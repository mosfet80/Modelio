= Links Editor

== Introduction

The Links Editor is a particular view of Modelio dedicated to visualizing, exploring and editing links in the model. Like any other view in Modelio, it can be shown/hidden at any moment.

The Links Editor is an all-in-one visualization, exploration and edition tool specialized in model links.
