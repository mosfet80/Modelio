= La recherche sous Modelio

Modelio propose plusieurs manières de rechercher un ou des élément(s). Il est possible d'effectuer :

* Une recherche rapide grâce au nom ou à l'identifiant d'un élément.
* link:./Modeler-_modeler_handy_tools_simple_search.adoc[Une recherche simple] permettant de filtrer les éléments en fonction de leur nom, type et de leur(s) propriété(s).
* link:./Modeler-_modeler_handy_tools_notes_search.adoc[Une recherche dans les notes] parcourant les descriptions et les documents liés à chaque élément. 
* link:./Modeler-_modeler_handy_tools_analyst_search.adoc[Une recherche Analyst] en filtrant les éléments par rapport à la valeur de leurs propriétés.
* link:./Modeler-_modeler_handy_tools_MQL_search.adoc[Une recherche par requête *MQL*] permettant de combiner recherche, filtrer et naviguer dans le modèle.

Ces différents type de recherches sont accessibles par l'intermédiaire: 

* Du menu Edition : 

image::images/search_edition_menu.png[Menu edition]

* De la barre d'outil dédiée de l'application :
 
image::images/search_tool_bar.png[Barre de recherche]

* et de la vue de "Résultat de la recherche" :

image::images/search_view.png[Vue recherche]

Les résultats, peu importe leur origine, seront toujours présentés dans une vue dédiée nommée "Résultats de Recherche".


==== Recherche Rapide

L'outil de recherche rapide de Modelio permet de retrouver facilement des éléments dans un modèle, simplement à partir de leur nom ou de leur identifiant.

S'il y a zéro correspondance, link:./Modeler-_modeler_handy_tools_simple_search.adoc[la fenêtre de recherche] est alors ouverte.
 
S'il n'y a qu'un seul élément correspondant, il est automatiquement sélectionné dans l'explorateur.

S'il y a plusieurs éléments correspondants, ils sont affichés dans la vue des résultats de recherche.

La *recherche rapide* contient également un historique des dernières recherches afin qu'elles puissent être facilement rejouées à tout moment.
