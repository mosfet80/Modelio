= Editeur de liens

== Introduction

L'éditeur de liens est une vue particulière de Modelio qui permet de visualiser, explorer, et éditer les liens du modèle. Comme les autres vues de Modelio, elle peut être affichée ou masquée à tout moment.

L'éditeur de liens est un outil tout-en-un de visualisation, exploration, et édition, spécialisé dans les liens de modèle.
