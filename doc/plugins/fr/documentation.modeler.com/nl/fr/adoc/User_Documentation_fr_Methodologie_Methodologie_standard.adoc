= Methodologie standard


Les liens méthodologiques standards sont apportés par Modelio via le module *ModelerModule*. Ils permettent de relier des éléments appartenant aux modèles UML, BPMN, ArchiMate et Analyst.

Ces liens sont pour la plupart visibles dans la vue Propriété, et ils sont aussi pris en compte dans les diagrammes pour activer des comportements avancés lors des démasquages.
