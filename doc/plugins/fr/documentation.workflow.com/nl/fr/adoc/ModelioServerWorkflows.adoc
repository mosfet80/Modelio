= Déploiement et gestion des permissions via Modelio Server

Afin de bénéficier de la gestion des permissions et des notifications, un projet doit être géré par un serveur *Modelio Server*.
Depuis le serveur Modelio Server, l'administrateur du projet peut ajouter des workflows et ensuite configurer les permissions et les notifications sur les transitions.

* <<AddWorkflowToProject.adoc#,Ajout d'un workflow dans un projet Modelio Server>>
