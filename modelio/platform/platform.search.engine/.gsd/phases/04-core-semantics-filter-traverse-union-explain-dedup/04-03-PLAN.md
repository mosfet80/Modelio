  <name>Task 1: Implement union step execution and verify deduplication</name>
  <files>
    platform.search.engine/src/org/modelio/platform/query/internal/executor/StepPipelineExecutor.java
  </files>
  <action>
Replace the placeholder UnionStep case in `StepPipelineExecutor.executeSteps()` with a call to a new private method `executeUnion(UnionStep step, List<NodeWithExplainOut> input, ICoreSession session)`.

Implement `executeUnion()`:

1. For each branch in `step.branches()` (each branch is a `List<ResolvedStep>`):
   - Execute the branch as a sub-pipeline: `executeSteps(branch, input, session)`.
   - Each branch receives the **same input** (all branches start from the same set of items).
   - Collect all branch results into a single merged list.

2. Return the merged list. No dedup inside union — dedup happens at pipeline end in `execute()`.

3. Handle empty branches gracefully: an empty branch (`List.of()`) produces the input unchanged (identity pipeline). If `step.branches()` itself is empty → return empty list.

**Verify deduplication logic in `execute()`**: The existing dedup code in `execute()` (from Plan 04-01) uses `LinkedHashSet<String>` keyed by `item.node().getUuid()`. Verify this is correct:
- Iterate the final pipeline output in order.
- For each item, `seen.add(item.node().getUuid())` returns true if new → push to filler.
- First-discovered path is kept (subsequent paths to same node are discarded).
- Order is preserved (LinkedHashSet maintains insertion order, and we iterate sequentially).

If the dedup is already correct from Plan 04-01, no changes needed to `execute()`. If not, fix it.

**Edge case handling**:
- Union with one branch → equivalent to just running that branch's steps.
- Union with all branches producing the same node → dedup keeps exactly one item (first branch's result).
- Union where branches have different step counts → each branch runs independently.

Log at DEBUG level: number of branches, total items per branch, total merged items.

  </verify>

StepPipelineExecutor handles UnionStep by executing all branches as sub-pipelines and merging results. Final deduplication keyed by UUID keeps first-discovered path.
