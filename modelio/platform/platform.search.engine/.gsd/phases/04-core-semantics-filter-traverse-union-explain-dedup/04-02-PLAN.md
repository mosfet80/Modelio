  <name>Task 1: Implement traverse step execution in StepPipelineExecutor</name>
  <files>
    platform.search.engine/src/org/modelio/platform/query/internal/executor/StepPipelineExecutor.java
  </files>
  <action>
Replace the placeholder TraverseStep case in `StepPipelineExecutor.executeSteps()` with a call to a new private method `executeTraverse(TraverseStep step, List<NodeWithExplainOut> input, ICoreSession session)`.

Implement `executeTraverse()`:

1. **Get MExpert**: `MExpert expert = session.getMetamodel().getMExpert();`

2. **Iterate input items**: For each `NodeWithExplainOut item` in input, for each `EdgeAlternative alt` in `step.edge().alternatives()`:

3. **If `alt` is `MDependencyEdge mde`**:
   - Call `List<MObject> targets = item.node().mGet(mde.dependency())`.
   - For each valid target (`target != null && target.isValid() && !target.isDeleted()`):
     - If `step.edgeFilter()` is not null: this is unexpected for MDependency (no link object), skip edgeFilter.
     - Create extended path: append `new MDependencyPathStepOutput(mde.dependency().getSource(), mde.dependency())` to path steps, append target to path nodes.
     - Create new `NodeWithExplainOut(target, extendedPath)`.
   - Track invalid elements encountered for warning diagnostic.

4. **If `alt` is `LinkObjectEdge loe`**:
   - Determine direction from `loe.direction()`:

   **FORWARD (node is source endpoint)**:
   - Get `Collection<MDependency> sourceDeps = loe.linkMetaclass().getLinkMetaclassSources()`.
   - For each `srcDep` in sourceDeps:
     - Get opposite: `MDependency opposite = srcDep.getSymetric()`.
     - If opposite is null → skip (cannot navigate).
     - If `opposite.getSource()` is not assignable from the node's metaclass → skip.
     - Get link objects: `List<MObject> links = item.node().mGet(opposite)`.
     - For each link: verify `link.getMClass().hasBase(loe.linkMetaclass())`.
     - If `loe.stereotype()` is not null, verify the link has the stereotype applied (cast to `ModelElement`, check `getExtension().contains(loe.stereotype())`).
     - If `step.edgeFilter()` is not null, evaluate it on the link: `ExpressionEvaluator.evaluate(step.edgeFilter(), link, session)`. Skip link if false.
     - Get far end: `MObject target = expert.getTarget(link)`.
     - Validity guard: check `target != null && target.isValid() && !target.isDeleted()`.
     - Create extended path: append `new LinkPathStepOutput(link, Direction.FORWARD)`, append target to nodes.
     - Create `NodeWithExplainOut(target, extendedPath)`.

   **BACKWARD (node is target endpoint)**:
   - Get `Collection<MDependency> targetDeps = loe.linkMetaclass().getLinkMetaclassTargets()`.
   - For each `tgtDep` in targetDeps:
     - Get opposite: `MDependency opposite = tgtDep.getSymetric()`.
     - If opposite is null → skip.
     - If `opposite.getSource()` is not assignable from the node's metaclass → skip.
     - Get link objects: `List<MObject> links = item.node().mGet(opposite)`.
     - For each link: verify `link.getMClass().hasBase(loe.linkMetaclass())`.
     - If stereotype filter, apply same as forward.
     - If edgeFilter, evaluate on link.
     - Get far end: `MObject source = expert.getSource(link)`.
     - Validity guard.
     - Path: `new LinkPathStepOutput(link, Direction.BACKWARD)`, append source to nodes.
     - Create `NodeWithExplainOut(source, extendedPath)`.

5. **Path extension helper**: Create a private static method `PathOutput extendPath(PathOutput existing, MObject newNode, PathStepOutput stepOutput)`:
   - `List<MObject> newNodes = new ArrayList<>(existing.nodes()); newNodes.add(newNode);`
   - `List<PathStepOutput> newSteps = new ArrayList<>(existing.steps()); newSteps.add(stepOutput);`
   - `return new PathOutput(List.copyOf(newNodes), List.copyOf(newSteps));`

6. **Invalid element tracking**: Collect skipped elements. After processing all items for this step, if any were skipped, push a warning diagnostic to a passed-in diagnostic list (or log with `SearchEngine.LOG`). Note: since `executeSteps()` doesn't have access to the filler, track skipped elements and emit a log warning. Alternatively, change `executeSteps` signature to accept a diagnostics collector `List<Diagnostic>` parameter, and have `execute()` push them to the filler. Choose the cleanest approach.

7. **Unknown edge**: If `step.edge().isUnknown()` → return empty list (no traversal possible), log warning.

Important implementation notes (from RESEARCH.md):
- Use `getSymetric()` (French spelling, NOT `getSymmetric` or `getOpposite`).
- Use `MExpert.getSource(link)` / `MExpert.getTarget(link)` universally — never cast to specific link types.
- Use `MClass.hasBase()` for metaclass checking, never manual parent walking.
- MDependencyEdge.direction() is always FORWARD per current resolved model.
