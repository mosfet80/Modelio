<objective>
Refactor StepPipelineExecutor.buildPipeline() to remove batching infrastructure and restore pure streaming semantics.

Purpose: The current implementation batches TraversalItems per source element into a NodeAccumulator, then flushes. This introduces path silencing (only first source path extracted), polluted globalEmitted state, and unnecessary complexity. The pipeline should emit immediately as items arrive.

Output: A simplified StepPipelineExecutor with no NodeAccumulator, no currentBatch, no globalEmitted — just a streaming terminal that emits one NodeWithExplainOut per (node, path) pair with UUID-based budget tracking.
</objective>

```java
Set<String> emittedNodeUuids = new HashSet<>();
Consumer<TraversalItem> terminal = item -> {
    if (downstream.isComplete()) return;
    String uuid = item.node().getUuid();
    boolean isNewNode = emittedNodeUuids.add(uuid);
    if (isNewNode && !budget.tryAccept()) {
        emittedNodeUuids.remove(uuid); // rollback
        if (!truncationFired[0]) {
            truncationFired[0] = true;
            downstream.setTruncated();
            downstream.pushDiagnostic(Diagnostics.info(DiagnosticCode.EXECUTION_TRUNCATED,
                    budget.getExhaustionCause()));
        }
        return;
    }
    downstream.pushItem(new NodeWithExplainOut(item.node(), List.of(item.path())));
};
```

3. **Rewrite** the returned `IQueryResponseFiller.pushItem()` method. Currently it does a 3-step clear/run/flush cycle. Replace with iteration over all source paths:
```java
@Override
public void pushItem(NodeWithExplainOut item) {
    if (isComplete()) return;
    for (PathOutput path : item.whyPaths()) {
        chainHead.accept(new TraversalItem(item.node(), path));
    }
}
```

4. **Simplify** the returned `IQueryResponseFiller.complete()` — keep empty body (no flush needed), update comment.

5. Remove unused imports: `LinkedHashMap`, `LinkedHashSet`, `Collection` (if no longer needed), `MObject` (if no longer needed for globalEmitted).

Keep imports: `HashSet`, `Set`, `List`.
