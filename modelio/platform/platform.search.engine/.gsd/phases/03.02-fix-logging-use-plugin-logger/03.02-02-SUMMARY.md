## Technical Details

### Before/After Pattern

**Old Pattern (System.Logger):**
```java
import java.lang.System;  // implicit, never explicitly imported

public class ClassName {
    private static final System.Logger LOG = System.getLogger(ClassName.class.getName());
    
    void someMethod() {
        LOG.log(System.Logger.Level.TRACE, "message");
    }
}
```

**New Pattern (PluginLogger):**
```java
import org.modelio.platform.search.engine.plugin.SearchEngine;
import org.modelio.platform.utils.log.writers.PluginLogger;

public class ClassName {
    private static final PluginLogger LOG = SearchEngine.LOG;
    
    void someMethod() {
        LOG.log(System.Logger.Level.TRACE, "message");  // API compatible
    }
}
```
