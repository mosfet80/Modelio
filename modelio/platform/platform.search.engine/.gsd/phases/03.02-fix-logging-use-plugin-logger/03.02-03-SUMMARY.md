### Task 3: Run executor tests ✅

**Objective:** Execute tests and verify logging behavior unchanged

**Initial Test Run (Before Logger Fix):**
- ❌ **Failures:** 8 test errors
- **Root Cause:** `SearchEngine.LOG` was null during test execution
- **Error:** `NullPointerException: Cannot invoke "PluginLogger.debug(String, Object[])" because ..LOG is null`

**Root Cause Analysis:**
- SearchEngine.LOG is initialized in OSGi bundle activation
- Unit tests don't trigger bundle activation
- Need test-time initialization

**Fix Applied:**
Added static initializer to `AbstractMqlTest` base class:
```java
static {
    if (SearchEngine.LOG == null) {
        SearchEngine.LOG = new PluginLogger("org.modelio.platform.query");
    }
}
```

## Technical Details

### Executor Logging Pattern

All three executor classes now follow identical pattern:

```java
import org.modelio.platform.search.engine.plugin.SearchEngine;
import org.modelio.platform.utils.log.writers.PluginLogger;

public class MyExecutor {
    private static final PluginLogger LOG = SearchEngine.LOG;

    void execute() {
        LOG.debug("Executing query: %s", name);
        LOG.log(System.Logger.Level.TRACE, "Detail: %s", detail);
    }
}
```

### API Compatibility Details

| Before (System.Logger) | After (PluginLogger) | Works |
|------------------------|----------------------|-------|
| `LOG.log(System.Logger.Level.TRACE, msg)` | `LOG.log(System.Logger.Level.TRACE, msg)` | ✓ |
| `LOG.log(System.Logger.Level.DEBUG, fmt, args...)` | `LOG.log(System.Logger.Level.DEBUG, fmt, args...)` | ✓ |
| N/A | `LOG.debug(msg)` | ✓ |
| N/A | `LOG.debug(fmt, args...)` | ✓ |

System.Logger.Level enum constants work unchanged with PluginLogger API.

### Test Infrastructure

Added `AbstractMqlTest` initialization to handle test logger:

```java
static {
    if (SearchEngine.LOG == null) {
        SearchEngine.LOG = new PluginLogger("org.modelio.platform.query");
    }
}
```

This runs once when test class loads, before any test methods execute. All test subclasses inherit this setup automatically.
