<task type="auto">
  <name>Task 2: Implement KindResolver (metaclass + stereotype + ambiguity diagnostics)</name>
  <files>
    platform.search.engine/src/org/modelio/platform/query/engine/resolver/KindResolver.java
  </files>
  <action>
    Implement `KindResolver` that resolves a kind token into `ResolvedKindRef`:

    - Input: raw token string.
    - Normalize: `trim()` only.
    - Resolve metaclass alternative:
      - `MClass mc = context.getMetaclass(trimmed)`; if non-null, include as `MetaclassKind`.
    - Resolve stereotype alternatives:
      - `List<Stereotype> sts = context.findStereotypesByName(trimmed)`; include each as `StereotypeKind`.

    Diagnostics behavior:
    - If 0 alternatives: emit a warning or error diagnostic (prefer WARNING unless it would prevent execution).
    - If >1 alternatives: emit a WARNING diagnostic describing ambiguity and listing the retained alternatives (names only; no expensive enumeration).

    Determinism:
    - Keep ordering deterministic (e.g., metaclass first, then stereotypes sorted by `getUuid()` or `getName()+getBaseClassName()`), but do not introduce case folding.
  </action>
  <verify>
    Add/adjust unit tests (next task) and run the test bundle aggregator.
  </verify>
  <done>
    KindResolver returns correct alternatives and produces diagnostics for unknown/ambiguous kinds.
  </done>
</task>
