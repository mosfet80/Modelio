# Phase 05.1 Plan 02: emitAllDepths=false Edge Case Tests Summary

**One-liner:** Two new RepeatStep tests cover emitAllDepths=false with maxDepth truncation and empty BFS at depth 1 in a chained pipeline.

## What Was Built

Added two test methods to `RepeatStepExecutionTest.java`, raising the total test count from 102 to 104.

### Test 5b — `repeat_emitAllDepthsFalse_maxDepthTruncation`

Validates that with `emitAllDepths=false` and `maxDepth=2`:
- BFS on `root→pkgA→pkgB→leaf` runs two levels: depth 1 discovers pkgA, depth 2 discovers pkgB.
- `leaf` (depth 3) is never reached.
- Only the maxDepth frontier `pkgB` is emitted; `pkgA` (intermediate) and `root/leaf` are not.

### Test 5c — `repeat_emitAllDepthsFalse_globalVisitedFiltersAll`

Validates two chained `emitAllDepths=false` RepeatSteps:
- `repeat1` receives `root`, BFS traverses to `leaf` (emitAllDepths=false → only deepest frontier emitted), passes `leaf` to `repeat2`.
- `repeat2` receives `leaf`, BFS from `leaf` finds no `OwnedElement` children → frontier empty at depth 1 → `depth==1` guard prevents emission → `repeat2` produces nothing.
- Net result: the pipeline terminal receives nothing → `response.items()` is empty.

## Deviations from Plan

### Corrected Test Expectation for Test 5c

**Found during:** Task 2 execution (test failure)

**Issue:** The plan stated "Net result: only leaf (from the first repeat)" and asserted `containsExactly(this.leaf)`. This assumption was based on an incorrect model of the pipeline: the plan assumed `repeat2` restarts from `root`, but in the actual push-based Consumer chain, `repeat2` receives `leaf` (the output of `repeat1`).

**Fix:** Updated Test 5c assertion from `containsExactly(this.leaf)` to `isEmpty()`, and rewrote the method comment to accurately describe the actual pipeline traversal.

**Correctness:** The corrected assertion reflects correct BFS pipeline semantics. `leaf` has no `OwnedElement` children → `repeat2`'s BFS terminates immediately at depth 1 → `emitAllDepths=false` with `depth==1` empty frontier → nothing emitted. This is the correct and expected behaviour.
