**1. Rewrite `resolveQuery()`**

Replace the current bridge implementation (from Plan 08-01) with the real per-step collection:

```java
@Override
public QueryResolutionResult resolveQuery(Query query) {
    // 1. Resolve source with dedicated diagnostics
    SourceResolutionResult sourceResult = resolveSource(query.getSource());
    ResolvedKind initialKind = resolveInitialKind(sourceResult.resolved());

    // 2. Resolve steps with per-step breakdown
    //    - Use an IdentityHashMap<Step, StepResolutionResult> to accumulate results
    //    - Track currentKind across the step chain
    //    - On unresolvable output kind (resolved step's outputKind is null or empty AND it's not a kind-preserving step): STOP resolving downstream steps
    //    - Downstream steps that are NOT resolved should be ABSENT from the map (per CONTEXT)
    Map<Step, StepResolutionResult> stepResults = new IdentityHashMap<>();
    List<ResolvedStep> resolvedSteps = new ArrayList<>();
    resolveStepsWithBreakdown(query.getSteps(), initialKind, stepResults, resolvedSteps, 0);

    // 3. Collect flat diagnostics list (union of source + all step diagnostics)
    List<Diagnostic> allDiagnostics = new ArrayList<>(sourceResult.diagnostics());
    for (StepResolutionResult sr : stepResults.values()) {
        allDiagnostics.addAll(sr.diagnostics());
    }

    // 4. Build result
    ResolvedQuery resolvedQuery = new ResolvedQuery(
        sourceResult.resolved() != null ? sourceResult.resolved() : new ResolvedSource.ProvidedSource(List.of()),
        List.copyOf(resolvedSteps),
        query.getLimits().freeze()
    );
    return new QueryResolutionResult(resolvedQuery, allDiagnostics, sourceResult, stepResults);
}
```

**2. Implement `resolveStepsWithBreakdown()`** (new private method)

```java
private void resolveStepsWithBreakdown(
        List<Step> steps,
        ResolvedKind initialKind,
        Map<Step, StepResolutionResult> stepResults,
        List<ResolvedStep> resolvedSteps,
        int depth) {

    if (steps == null || steps.isEmpty()) return;

    // Nesting depth check
    if (depth >= ResolutionLimits.ERROR_DEPTH) {
        // Emit ERROR diagnostic for first step and stop
        List<Diagnostic> depthDiag = List.of(Diagnostics.error(
            DiagnosticCode.RESOLUTION_ERROR,
            SearchEngine.I18N.getMessage("MQL.resolver.depth.error", depth)));
        stepResults.put(steps.get(0), new StepResolutionResult(steps.get(0), null, depthDiag));
        return;
    }
    if (depth >= ResolutionLimits.WARNING_DEPTH) {
        // Emit WARNING on first step but continue resolution
        // (don't stop — just warn)
    }

    ResolvedKind currentKind = (initialKind == null) ? ResolvedKind.empty() : initialKind;

    for (Step step : steps) {
        StepResolutionResult result = resolveStep(step, currentKind, depth);
        stepResults.put(step, result);

        if (result.resolved() == null) {
            // Unresolvable step — stop downstream resolution
            // Remaining steps will be absent from stepResults map
            break;
        }

        resolvedSteps.add(result.resolved());

        // Check if output kind is usable
        ResolvedKind outputKind = result.resolved().outputKind();
        if (outputKind == null || outputKind.isUnknown()) {
            // Check if this step type preserves input kind on failure
            if (isKindPreservingStep(step)) {
                currentKind = currentKind; // preserved
            } else {
                // Unresolvable output kind — stop downstream
                break;
            }
        } else {
            currentKind = outputKind;
        }
    }
}
```

**3. Implement the overloaded `resolveStep(Step, ResolvedKind, int depth)`** (private, with depth tracking)

This is the heart of error-resilient step resolution. For each step type:

```java
private StepResolutionResult resolveStep(Step step, ResolvedKind currentKind, int depth) {
    List<Diagnostic> diagnostics = new ArrayList<>();

    // Depth warning (if applicable and not already emitted at breakdown level)
    if (depth >= ResolutionLimits.WARNING_DEPTH && depth < ResolutionLimits.ERROR_DEPTH) {
        diagnostics.add(Diagnostics.warning(DiagnosticCode.RESOLUTION_ERROR,
            SearchEngine.I18N.getMessage("MQL.resolver.depth.warning", depth)));
    }

    try {
        ResolvedStep resolved = switch (step) {
            case FilterStep filterStep -> resolveFilterStepSafe(filterStep, currentKind, diagnostics);
            case TraverseStep traverseStep -> resolveTraverseStepSafe(traverseStep, currentKind, diagnostics);
            case UnionStep unionStep -> resolveUnionStepSafe(unionStep, currentKind, diagnostics, depth);
            case RepeatStep repeatStep -> resolveRepeatStepSafe(repeatStep, currentKind, diagnostics, depth);
        };
        return new StepResolutionResult(step, resolved, diagnostics);
    } catch (Exception e) {
        // NEVER throw — wrap into ERROR diagnostic
        diagnostics.add(Diagnostics.error(DiagnosticCode.RESOLUTION_ERROR,
            SearchEngine.I18N.getMessage("MQL.resolver.step.exception", e.getMessage())));
        return new StepResolutionResult(step, null, diagnostics);
    }
}
```

**4. Implement safe step resolution methods:**

`resolveFilterStepSafe`: If `filterStep.getWhere()` is null, emit REQUIRED_FIELD_MISSING diagnostic, return FilterStep with null predicate and **output kind = input kind** (kind-preserving, per CONTEXT). Otherwise resolve expression normally.

`resolveTraverseStepSafe`: If `traverseStep.getEdge()` is null or blank, emit REQUIRED_FIELD_MISSING diagnostic, return **null** (stops downstream, per CONTEXT — traverse with unknown edge cannot produce output kind). Otherwise resolve edge normally (delegate to existing resolveEdge).

`resolveUnionStepSafe`: If `unionStep.getBranches()` is null or empty, emit REQUIRED_FIELD_MISSING diagnostic, return UnionStep with empty branches and output kind = input kind. For each branch, call `resolveStepsWithBreakdown()` — if a branch fails, its child steps are absent from the stepResults map but other branches continue. If at least one branch succeeded, the outer pipeline continues. If ALL branches fail, return null (stop downstream).

`resolveRepeatStepSafe`: Resolve body via `resolveStepsWithBreakdown()`. If any step in the body fails (unresolvable output kind), stop ALL resolution including outer pipeline (per CONTEXT: "Fatal"). Return null to signal outer pipeline to stop.
