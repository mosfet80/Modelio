**1. Rewrite MqlValidationService**

Replace the entire content of `MqlValidationService.java` with a thin orchestrator that delegates ALL validation to `IQueryResolver.resolveQuery()`:

```java
public class MqlValidationService {
    private final IQueryResolver resolver;
    private QueryResolutionResult lastResult;

    public MqlValidationService(IQueryResolver resolver) {
        this.resolver = Objects.requireNonNull(resolver, "resolver");
    }

    /**
     * Re-resolve the given query and cache the result.
     * Call this on every model change.
     */
    public void resolve(Query query) {
        if (query == null) {
            this.lastResult = null;
            return;
        }
        this.lastResult = this.resolver.resolveQuery(query);
    }

    /**
     * Get the last resolution result.
     */
    public QueryResolutionResult getLastResult() {
        return this.lastResult;
    }

    /**
     * Get per-step diagnostics for a given Step (identity-based lookup).
     * Returns empty list if step was not resolved or no result available.
     */
    public List<Diagnostic> getDiagnosticsFor(Step step) {
        if (this.lastResult == null || this.lastResult.stepResults() == null) {
            return List.of();
        }
        StepResolutionResult sr = this.lastResult.stepResults().get(step);
        return sr != null ? sr.diagnostics() : List.of();
    }

    /**
     * Get per-source diagnostics.
     */
    public List<Diagnostic> getSourceDiagnostics() {
        if (this.lastResult == null || this.lastResult.sourceResult() == null) {
            return List.of();
        }
        return this.lastResult.sourceResult().diagnostics();
    }

    /**
     * Check if any ERROR-level diagnostic exists in the last resolution.
     */
    public boolean hasErrors() {
        if (this.lastResult == null) return false;
        return this.lastResult.diagnostics().stream()
            .anyMatch(d -> d.level() == Diagnostic.Level.ERROR);
    }

    /**
     * Get the flat list of all diagnostics from the last resolution.
     */
    public List<Diagnostic> getAllDiagnostics() {
        if (this.lastResult == null) return List.of();
        return this.lastResult.diagnostics();
    }
}
```

Remove all old `validateXxx()` methods. The class should be ~60-80 lines total.

**1. Implement diagnostic rendering in figures**

Each figure (MqlSourceFigure, MqlFilterFigure, MqlTraverseFigure, MqlUnionFigure, MqlRepeatFigure) already has a `setWarningText(String)` method with a label. Replace this pattern with a richer diagnostic display:

Replace the existing `warningLabel` field in each figure with a **diagnostic label** that supports severity-based styling:

```java
// In each figure class, replace the existing warning pattern:
private final Label diagnosticLabel;

// In constructor:
this.diagnosticLabel = new Label("");
this.diagnosticLabel.setVisible(false);
add(this.diagnosticLabel);

/**
 * Set the diagnostic display for this figure.
 * Shows worst-severity icon prefix and a summary message.
 * Tooltip shows all diagnostic messages.
 */
public void setDiagnostics(List<Diagnostic> diagnostics) {
    if (diagnostics == null || diagnostics.isEmpty()) {
        this.diagnosticLabel.setVisible(false);
        this.diagnosticLabel.setToolTip(null);
        return;
    }

    // Determine worst severity
    Diagnostic.Level worst = null;
    for (Diagnostic d : diagnostics) {
        if (worst == null || d.level().compareTo(worst) > 0) {
            worst = d.level();
        }
    }

    // Set icon prefix based on severity level
    String prefix = switch (worst) {
        case ERROR -> "\u274C "; // ❌
        case WARNING -> "\u26A0\uFE0F "; // ⚠️
        case INFO -> "\u2139\uFE0F "; // ℹ️
    };

    // Show worst message in the label
    String worstMessage = diagnostics.stream()
        .filter(d -> d.level() == worst)
        .map(Diagnostic::message)
        .findFirst()
        .orElse("");
    this.diagnosticLabel.setText(prefix + worstMessage);
    this.diagnosticLabel.setVisible(true);

    // Set color based on severity
    switch (worst) {
        case ERROR -> this.diagnosticLabel.setForegroundColor(ColorConstants.red);
        case WARNING -> this.diagnosticLabel.setForegroundColor(ColorConstants.orange);
        case INFO -> this.diagnosticLabel.setForegroundColor(ColorConstants.blue);
    }

    // Build tooltip with ALL diagnostics
    StringBuilder tooltip = new StringBuilder();
    for (Diagnostic d : diagnostics) {
        if (tooltip.length() > 0) tooltip.append("\n");
        String levelPrefix = switch (d.level()) {
            case ERROR -> "ERROR: ";
            case WARNING -> "WARNING: ";
            case INFO -> "INFO: ";
        };
        tooltip.append(levelPrefix).append(d.message());
    }
    this.diagnosticLabel.setToolTip(new Label(tooltip.toString()));
}
```
